# Archive note

Early `README.md` text on this repository was a single long letter.

It mixed:

- personal voice,
- mission claims,
- jurisdictional *intent*,
- and comparisons.

That is normal for a founder-led start. As AIC matured, **MyVision** was upgraded so that:

1. **Letters** stay letters (dated, human).  
2. **Principles** stay stable boundaries (is / is not).  
3. **Roadmap** stays intent, not promise.  
4. **Comparisons** stay analytical, not scoreboards.

If an older phrase conflicts with the Charter or Ethical Kernel in protocol repos, **Charter / kernel win**.
